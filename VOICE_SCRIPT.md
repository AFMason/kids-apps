# Voice Script

Record these in the app: on the home screen, **hold ⚙️ for 3 seconds**, tap 🎙️ Record voices, then tap ● beside each line (tap again to stop). Any line you skip uses the robot voice.

**Tips**
- Sound excited and warm, a little slower than normal. Smile while you talk.
- Leave a short gap before and after each line. Keep each clip short.
- **Numbers and items get stitched together** (e.g. "Hi! I would like" + "six" + "cupcakes" + "please!"). Say them in a flat, neutral tone, not like a question or the end of a sentence, so they join smoothly.
- Quiet room, about a hand's length from the tablet.
